Completed concept Table:
Repository: Project full file with its history 
Working tree: The current file that are being edit
Staging area: List of file or change that have been selected for the next Commit
Commit: A confirm file that will be push to github with a message from the author with date
Branch: A pointer in a line of commits, use in parallel work
Merge: A combine file of two branch
Remote: Copy of repository from GitHub
Push/Pull/Clone: Push is uploading commit to remote, pull is downloading latest commit from github to local computer, and clone is copy a remote repository
